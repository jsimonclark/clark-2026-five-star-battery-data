# Supporting files for How to Publish Five-Star Battery Data

`five_star_queries/` holds the notebook that merges the JSON-LD metadata of the three case-study deposits into one graph and queries it, with the files it reads and its results. `dataset_survey/` holds the per-dataset results of the Battery Data Commons survey.

Everything here is CC BY 4.0, except the metadata copies in `five_star_queries/metadata/`, which keep the licences of their deposits.
